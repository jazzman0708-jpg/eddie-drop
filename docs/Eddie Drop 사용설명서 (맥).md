# Eddie Drop 사용설명서 (맥)

프리미어 프로 안에서 **스톡 영상 · 이미지 · 밈 · 스티커 · 효과음**을 찾아
곧바로 타임라인에 넣는 패널입니다.

브라우저와 파일 탐색기를 오갈 필요 없이, 프리미어 안에서 다 끝납니다.

**버전 1.0.9**

---

## 무엇이 되나요

| 탭 | 하는 일 | 어디서 가져오나 |
|---|---|---|
| **영상** | 무료 스톡 영상 검색 → 타임라인에 삽입 | Pexels · Pixabay |
| **이미지** | 무료 사진 검색 → 삽입 | Pexels · Pixabay |
| **밈** | 짤 검색 → MP4로 받아서 삽입 | GIPHY |
| **스티커** | 투명 배경 스티커 검색 → 삽입 | GIPHY |
| **효과음** | 효과음 검색 → **볼륨까지 맞춰서** 삽입 | Freesound (CC0만) |
| **내 파일** | 내 컴퓨터 소스를 훑어보고 삽입 | 내 컴퓨터 |
| **설정** | API 키, 저장 폴더, 동작 방식 | |

# 1. 설치하기

## 받는 곳

https://github.com/jazzman0708-jpg/eddie-drop/releases/latest

받을 파일: **EddieDrop-1.0.9-mac.pkg**

## 설치하기 전에

**프리미어 프로를 완전히 종료해 주세요.**
켜둔 채로 설치하면 파일이 잠겨서 패널이 나타나지 않습니다.

## 설치 순서

### 1. 받은 파일을 오른쪽 클릭 → **열기**

두 번 클릭하면 열리지 않습니다. 반드시 **오른쪽 클릭 → 열기** 로 여세요.
(`Control` 키를 누른 채 클릭해도 됩니다)

### 2. "확인되지 않은 개발자" 경고 — 정상입니다

> **"확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다"**

애플 개발자 인증서(연 129달러)를 쓰지 않아서 나오는 경고입니다.
파일에 문제가 있다는 뜻이 아닙니다.

다시 뜨는 창에서 **열기** 를 누르면 진행됩니다.

> macOS 15 이상에서 이 방법이 막히면
> **시스템 설정 → 개인정보 보호 및 보안** 으로 가세요.
> 화면 아래쪽에 "EddieDrop… 이 차단되었습니다" 와 함께
> **[그래도 열기]** 버튼이 있습니다.

### 3. 안내대로 계속 → 설치

**관리자 암호를 묻지 않습니다.** 사용자 폴더 안에만 설치되기 때문입니다.


설치 위치: `~/Library/Application Support/Adobe/CEP/extensions/com.eddie.drop`

### 4. 프리미어를 켜고 **창 → 확장명 → Eddie Drop**

# 2. API 키 넣기 (처음 한 번만)

Eddie Drop은 **여러분의 키로** 각 사이트에서 직접 검색합니다.
그래서 키가 다른 서버로 전송되지 않고, **여러분 컴퓨터에만 저장됩니다.**
키는 전부 **무료**입니다.

## 어디서 받나요

패널의 **설정** 탭을 열면 각 칸 옆에 **[키 발급받기 ↗]** 링크가 있습니다.

| 사이트 | 무엇에 쓰나 | 무료 한도 |
|---|---|---|
| **Pexels** | 영상 · 이미지 | 시간당 200회 · 월 20,000회 |
| **Pixabay** | 영상 · 이미지 | 60초당 100회 |
| **GIPHY** | 밈 · 스티커 | 시간당 100회 |
| **Freesound** | 효과음 | 분당 60회 · 하루 2,000회 |

> 개인 편집 작업에서 이 한도를 넘기기는 어렵습니다.
> 넘으면 "요청 한도를 넘었습니다" 라고 알려주고, 잠시 뒤 저절로 풀립니다.

## 넣는 법

1. **설정** 탭을 엽니다
2. 각 칸에 키를 **붙여넣습니다** — 바로 저장됩니다
3. **[연결 테스트]** 를 눌러 `연결 성공` 이 뜨는지 확인합니다

> **키를 복사할 때 뒤가 잘리는 일이 자주 있습니다.**
> 연결 테스트가 실패하면 키를 전체 선택해서 다시 복사해 보세요.

## 키는 어디에 저장되나요

```
~/Library/Application Support/Eddie
```

본인만 읽을 수 있게 권한이 걸려 저장됩니다.
다른 에디 플러그인과 **같이 쓰기 때문에 한 번만 넣으면 됩니다.**

# 3. 기본 사용법

## 넣는 방법은 네 가지입니다

| 방법 | 어떻게 | 언제 쓰나 |
|---|---|---|
| **[삽입] 버튼** | 카드에 마우스를 올리면 나옵니다 | **가장 확실합니다** |
| **[덮어쓰기] 버튼** | 위와 같음 | 뒤 클립을 밀지 않고 덮을 때 |
| **끌어놓기** | 카드를 타임라인으로 끕니다 | 원하는 위치에 정확히 놓을 때 |
| **`,` `.` 키** | 고른 뒤 누릅니다 | 빠르게 연달아 넣을 때 |

끌어다 놓은 파일도 잠시 뒤 `Eddie Drop / Pexels` 같은 소스별 빈으로 정리됩니다.

## 단축키

| 키 | 하는 일 |
|---|---|
| 클릭 | 고르기 (효과음은 바로 들림) |
| 더블클릭 | 소스 모니터에 열기 |
| **Tab** | 다음 결과 |
| **Shift + Tab** | 이전 결과 |
| **Space** | 미리보기 / 미리듣기 |
| **`,`** | 플레이헤드 위치에 삽입 |
| **`.`** | 플레이헤드 위치에 덮어쓰기 |

> ### ⚠️ `,` 와 `.` 를 쓸 때 알아두실 점
>
> 이 두 키는 **프리미어에서도 같이 동작합니다.**
> 그래서 **소스 모니터에 다른 클립이 열려 있으면 그 클립도 함께 들어갑니다.**
>
> 어도비 확장 규격(CEP)의 제약이라 저희가 막을 수 없습니다.
>
> **깔끔하게 넣으려면 [삽입] 버튼이나 끌어놓기를 쓰세요.**

> 방향키(↑↓←→)는 프리미어가 가져가 버려서 쓸 수 없습니다.
> 대신 **Tab / Shift+Tab** 으로 결과를 넘기세요.
>
> Enter 도 쓰지 않습니다. 프리미어의 인/아웃 렌더가 같이 돌기 때문입니다.
> 소스 모니터에 열려면 **더블클릭**하세요.

## 어느 트랙에 들어가나요

1. **타겟이 켜져 있는 트랙**에 들어갑니다
2. 타겟이 없으면 **비어 있는 트랙**을 찾아서 넣습니다
3. 빈 트랙이 없으면 맨 위 트랙에 넣고 **"트랙을 하나 추가하면 더 안전합니다"** 라고 알려줍니다

## 받은 파일은 어디에 저장되나요

```
~/Documents/Eddie Drop
  Pexels/   Pixabay/   GIPHY/   Freesound/   _thumbs/
```

설정 탭에서 폴더를 바꿀 수 있습니다.
프로젝트 안에서는 **`Eddie Drop / Pexels`** 처럼 소스별 빈으로 정리됩니다.

## 화면을 넓게 쓰기

검색창과 결과 사이에 **경계선**이 있습니다. 위아래로 끌면 크기가 바뀝니다.

- **끝까지 위로 끌면** 검색창만 남고 결과가 화면을 꽉 채웁니다
- **두 번 클릭**하면 원래대로 돌아갑니다
- 좁혀도 필터는 사라지지 않고 **스크롤로** 쓸 수 있습니다
- 맞춰둔 크기는 **탭마다 따로 기억**합니다

# 4. 탭별 사용법

## 영상 · 이미지 탭

**Pexels · Pixabay · 둘 다** 중에서 고를 수 있습니다.

필터
- 방향: 가로 / 세로 / 정사각
- 크기: 4K 이상 / FHD 이상 / HD 이상
- 색상: 12가지
- **fps**: 24fps(영화) / 25fps(PAL) / 30 / 50 / 60 / 50fps 이상(슬로우모션)

> **fps 필터와 방향 필터는 Pexels 결과에만 적용됩니다.**
> Pixabay가 그 정보를 주지 않기 때문입니다. 패널이 그때그때 알려줍니다.

받는 화질은 **설정 → 영상 기본 화질** 을 따릅니다 (4K / FHD / HD).
이미지는 항상 원본 크기로 받습니다. JPG뿐 아니라 **PNG(투명 배경 포함)** 도 받습니다.

> Pixabay는 이미지 핫링크 금지 규정이 있어 썸네일도 먼저 내려받아 보여줍니다.
> 그래서 Pixabay 결과는 썸네일이 조금 늦게 뜹니다.

## 밈 탭

짤을 **MP4로** 받습니다. 프리미어에서 GIF보다 훨씬 가볍게 돌아갑니다.

- 한글보다 **영어로 검색하면 결과가 훨씬 많습니다**
- 수위는 기본 **전체 이용가(G)** 로 맞춰져 있습니다

> **방송·영화 장면 짤은 저작권이 있을 수 있습니다. 수익화 영상에서는 주의하세요.**

## 스티커 탭

**투명 배경이 살아 있는 GIF**로 받습니다. 배경 없이 바로 얹을 수 있습니다.
카드가 체크무늬로 보이면 투명하다는 뜻입니다.

## 효과음 탭

**출처를 적지 않아도 되는 소리(CC0)만** 검색됩니다. 이 설정은 끌 수 없습니다.

사용법
1. 태그 칩을 누르거나 검색어를 칩니다 (한글도 됩니다)
2. **줄을 클릭하면 바로 들립니다**
3. **Tab** 으로 다음 소리를 착착 넘겨 들어봅니다
4. 마음에 들면 `,` 또는 **[삽입]**

**볼륨이 자동으로 맞춰집니다**
넣기 전에 소리의 가장 큰 부분을 재서, 목표 크기(기본 **-15dB**)에 맞춰
클립 볼륨을 조절해 넣습니다. 효과음마다 볼륨이 들쭉날쭉하지 않습니다.
목표 크기는 **설정 → 효과음 목표 레벨** 에서 바꿀 수 있습니다.

태그 칩은 설정 탭에서 추가·삭제할 수 있습니다.
직접 추가한 한글 단어도 검색창에서 그대로 쓸 수 있습니다.

> **음질 안내**
> Freesound는 원본 파일을 받으려면 별도 로그인이 필요해서,
> Eddie Drop은 **미리듣기용 MP3**를 받습니다. 44.1kHz 스테레오 · 약 100~235kbps 입니다.
> **효과음(휘릭·뿅·클릭 등)에는 충분하지만, 음악이나 긴 배경음으로 쓰기에는 권하지 않습니다.**

## 내 파일 탭

내 컴퓨터 폴더를 프로젝트 패널처럼 훑어봅니다.

- **[폴더 선택]** 으로 폴더를 고릅니다
- 자주 쓰는 폴더는 **자동으로 칩에 기억됩니다** (최대 6개)
- **[썸네일 보기] / [목록 보기]** 를 바꿀 수 있습니다
- 정렬 7가지 · 종류 필터 · 이름 검색
- **[이 폴더 전체를 프로젝트로 불러오기]** 로 한 번에 넣을 수 있습니다

읽는 파일 종류

| 종류 | 확장자 |
|---|---|
| 영상 | mp4 · mov · m4v · avi · mkv · webm · mxf · mpg · mpeg · wmv |
| 이미지 | jpg · jpeg · png · gif · tif · tiff · webp · bmp · heic |
| 소리 | mp3 · wav · aif · aiff · m4a · flac · ogg · aac |

알아두실 점
- `하위 폴더까지` 를 켜면 **깊이 제한 없이 끝까지** 찾습니다
- 한 번 읽은 폴더는 기억해 두어, 다시 들어오면 바로 보여줍니다
- 폴더를 새로 읽으려면 **[새로고침]** 을 누르세요
- **MOV / ProRes 파일은 썸네일과 미리보기가 안 나옵니다** (브라우저가 그 코덱을 못 읽습니다).
  이런 파일이 많으면 **[목록 보기]** 를 쓰세요

# 5. 업데이트

**설치 파일을 다시 깔 필요가 없습니다.**

- **설정 → 업데이트 → [업데이트 확인]**
- 새 버전이 있으면 **[업데이트]** 를 누르면 됩니다
- 프리미어를 켤 때 자동으로 확인하게 해둘 수도 있습니다 (기본 켜짐)

**문제가 생겨도 괜찮습니다**
새 버전이 제대로 안 열리면 **다음에 켤 때 저절로 이전 버전으로 돌아갑니다.**
직접 되돌리려면 **설정 → 업데이트 → [이전 버전으로 되돌리기]**.

## 기존 버전이 있을 때

그냥 새 설치 파일을 실행하면 됩니다.

- 기존 버전은 자동으로 정리됩니다
- **입력해 둔 API 키와 설정은 그대로 유지됩니다**
- 받아둔 소스 파일도 그대로 남습니다

## 지우고 싶을 때

아래 폴더를 지우면 됩니다.

```
~/Library/Application Support/Adobe/CEP/extensions/com.eddie.drop
```


설정과 받아둔 파일은 **일부러 남겨둡니다.** 직접 지우셔야 합니다.

```
~/Library/Application Support/Eddie        API 키 · 설정
~/Documents/Eddie Drop    받아둔 소스
```

# 6. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| **메뉴에 Eddie Drop 이 없다** | 프리미어를 완전히 껐다 켜보세요. 설치할 때 프리미어가 켜져 있었다면 다시 설치해 주세요 |
| **패널이 열리는데 하얗다** | 잠깐 기다려 주세요. 처음 열 때 기능 파일을 준비합니다 |
| **"기능 파일을 준비하지 못했습니다"** | `~/Library/Application Support/Eddie` 안의 `plugins` 폴더를 지우고 패널을 다시 열어보세요 |
| **`설정 탭에서 API 키를 넣어주세요`** | 설정 탭에서 해당 사이트 키를 넣으세요 |
| **`연결 테스트` 실패** | 키 뒤가 잘렸을 수 있습니다. 전체 선택해서 다시 복사하세요 |
| **`시퀀스를 먼저 열어주세요.`** | 시퀀스를 만들거나 열고 다시 시도하세요 |
| **`요청 한도를 넘었습니다`** | 잠시 기다리면 저절로 풀립니다 |
| **엉뚱한 클립이 같이 들어간다** | 소스 모니터에 열린 클립이 함께 삽입된 것입니다. **[삽입] 버튼**이나 끌어놓기를 쓰세요 |
| **`빈 트랙이 없어서 맨 위 트랙에 넣었어요`** | 트랙을 하나 더 추가하면 안전합니다 |
| **검색이 안 되고 결과도 없다** | 설정 → 진단 → **[프리미어 연결 확인]** 을 눌러보세요 |
| **결과가 너무 적다** | **영어로 검색**하면 결과가 훨씬 많습니다 |
| **썸네일이 안 보인다 (내 파일)** | MOV/ProRes는 미리보기가 안 나옵니다. **[목록 보기]** 를 쓰세요 |
| **하드가 꽉 찬다** | 설정 → 다운로드 → **[썸네일 캐시 비우기]**, 그리고 `~/Documents/Eddie Drop` 를 정리하세요 |

# 7. 라이선스 — 받은 소스를 써도 되나요

| 사이트 | 상업적 이용 | 출처 표기 |
|---|---|---|
| **Pexels** | 가능 | 필수는 아니지만 **권장** |
| **Pixabay** | 가능 | 필수는 아니지만 **권장** |
| **GIPHY** | 콘텐츠마다 다름 | ⚠️ **방송·영화 장면 짤은 저작권 주의** |
| **Freesound (CC0만)** | 가능 | **필요 없음** |

> 결과 묶음 위의 **[Pexels에서 보기 ↗]** 같은 링크를 누르면 원래 사이트로 갑니다.

## 부록 1. 이 플러그인이 해결하는 문제

### 스톡 영상 하나를 타임라인에 넣기

| | 플러그인 없이 | Eddie Drop |
|---|---|---|
| **조작 횟수** | **7번** | **3번** (끌어놓기는 **2번**) |
| 1 | 브라우저를 켠다 | 패널에서 검색어를 친다 |
| 2 | Pexels 사이트에서 검색한다 | 원하는 카드를 클릭한다 |
| 3 | 영상을 고르고 해상도를 골라 내려받는다 | `,` 를 누른다 → 플레이헤드 위치에 들어감 |
| 4 | 다운로드 폴더에서 파일을 찾는다 | |
| 5 | 프리미어 프로젝트 패널로 끌어다 놓는다 | |
| 6 | 프로젝트 패널에서 더블클릭해 소스 모니터로 연다 | |
| 7 | 타임라인에 삽입한다 | |

**중간에 프로그램을 몇 번 오가나**
- 없이: 브라우저 ↔ 파인더 ↔ 프리미어 — **3개 프로그램**
- Eddie Drop: **프리미어 안에서만**

### 효과음 하나 넣기

| | 플러그인 없이 | Eddie Drop |
|---|---|---|
| **조작 횟수** | **8번** | **3번** |
| | 사이트 검색 → 로그인 → 내려받기 → 파일 찾기 → 가져오기 → 타임라인에 놓기 → **오디오 미터 보며 볼륨 수동 조절** → 라이선스 확인 | 검색 → 클릭(바로 들림) → `,` |
| 볼륨 | 귀와 미터로 직접 맞춤 | **자동으로 목표 레벨에 맞춰서 들어감** |
| 라이선스 | 소리마다 직접 확인 | **CC0만 검색되게 고정** (끌 수 없음) |

> 볼륨 자동 맞추기는 Eddie Drop만의 기능입니다. 대본에서 강조할 지점입니다.

## 부록 2. 시연 시나리오 3개

> **측정 조건** — Premiere Pro 26.3.0 / macOS / 검색 캐시를 비우고 처음 검색하는 상태로 실측.
> 인터넷 속도와 파일 크기에 따라 달라집니다. **아래는 "이 정도로 빠르다"는 참고값이지, 보장값이 아닙니다.**

### 시나리오 ① 브이로그 B롤 채우기

- **검색어: `autumn forest`** (영상 탭)
- 흐름: 검색 → 카드 클릭 → `,`
- **실측: 검색 1.1초 + 넣기 0.6초 = 약 1.7초** (7.4 MB 파일)
- 단, 큰 파일은 더 걸립니다 — `sunset beach` 로 127 MB 짜리를 받았을 때는 **넣기까지 8.7초**
- 보여줄 포인트: **fps 필터** — `24fps (영화)` 를 골라서 내 시퀀스 프레임레이트에 맞는 것만 고르는 장면

### 시나리오 ② 정보전달 영상에 짤 넣기

- **검색어: `facepalm`** (밈 탭) / 스티커는 **`arrow`** 또는 **`하트`**
- 흐름: 검색 → 카드 클릭 → `,`
- **실측: 검색 1.0초 + 넣기 0.6초 = 약 1.6초**
- 보여줄 포인트:
  - GIF는 **MP4로 받아서** 프리미어가 가볍게 돌아간다는 점
  - **스티커 탭에서 투명 배경**이 그대로 살아나는 장면 (확인 완료 — 잘 나옵니다)

### 시나리오 ③ 효과음 붙이기

- **검색어: `magic sparkle`** 또는 태그 칩 **`휘릭`**
- 흐름: 태그 클릭 → 줄 클릭(바로 들림) → `Tab` 으로 몇 개 넘겨 듣기 → `,`
- **실측: 검색 2.1초 + 넣기 2.0초 = 약 4.1초** (볼륨 재는 시간 포함)
- 결과 표시: `삽입 완료 · A1 트랙 · 레벨 -8.2dB (피크 -0.3→-8.5dB)`
- 보여줄 포인트 — **이 시나리오가 제일 강합니다**
  1. `Tab` 만 눌러서 소리를 착착 넘겨 듣는 장면
  2. 넣자마자 **오디오 미터**가 목표 레벨에 딱 맞는 장면
  3. 맨 아래 **CC0 배지**를 보여주며 "출처 안 적어도 된다" 설명

## 부록 3. 촬영 전 확인 목록

### 프리미어 쪽

- [ ] **시퀀스를 미리 만들어 둘 것** — 없으면 `시퀀스를 먼저 열어주세요.` 만 뜹니다
- [ ] 트랙을 **V1~V3, A1~A4 정도** 만들어 둘 것 (빈 트랙이 없으면 "맨 위 트랙에 넣었어요" 경고가 뜹니다)
- [ ] **소스 모니터를 비워 둘 것** — 뭔가 열려 있으면 `,` 를 눌렀을 때 그것도 같이 들어가서 화면이 지저분해집니다
- [ ] 시퀀스 프레임레이트를 정해 둘 것 (fps 필터 시연을 하려면)
- [ ] **오디오 미터를 화면에 띄워 둘 것** — 볼륨 자동 맞추기가 시각적으로 보여야 설득력이 생깁니다

### Eddie Drop 쪽

- [ ] API 키 4개 모두 `연결 테스트` **연결 성공** 확인
- [ ] 설정 → **효과음 목표 레벨**을 **-15dB** 로 되돌릴 것 ⚠️ **지금 -8.5dB 로 되어 있습니다**
- [ ] 설정 → **검색 결과 캐시 비우기** — 캐시가 있으면 검색이 너무 빨리 끝나서 "실제로 찾고 있다"는 느낌이 안 납니다. 반대로 빠른 걸 보여주려면 캐시를 남겨두세요
- [ ] 다운로드 폴더를 한번 비우거나, 파인더로 열어서 파일이 쌓이는 걸 보여줄 준비
- [ ] 내 파일 탭 시연용 **폴더 하나 준비** (영상·이미지·소리가 섞인 폴더가 좋습니다)

### 화면 배치

- [ ] Eddie Drop 패널을 **세로로 길게** 두는 게 좋습니다 (카드가 2~3열로 보임)
- [ ] 패널 · 타임라인 · 오디오 미터가 **한 화면에 같이** 보이게
- [ ] 화면 녹화 해상도에서 패널 글자가 읽히는지 미리 확인

### 미리 찍어둘 장면

- [ ] 스티커 투명 배경 (확실히 잘 나옵니다)
- [ ] 효과음 `Tab` 연타로 넘겨 듣기
- [ ] 효과음 넣은 직후 오디오 미터
- [ ] 끌어놓기로 타임라인에 바로 놓기
