> **이 문서의 규칙**
> 실제로 코드에 들어 있고 프리미어에서 돌려본 것만 적었습니다.
> 숫자는 전부 실측값이거나 공식 문서 값이고, 출처를 옆에 적었습니다.
> 아직 확인 못 한 것은 **「확인 필요」** 로 표시했습니다. 대본에 쓰기 전에 꼭 짚어주세요.

> 기준 버전 **v1.0.7** · 확인 환경: Premiere Pro 26.3.0 (macOS)
> 윈도우는 설치까지만 실기기에서 확인했습니다 (아래 「확인 못 한 것」 참고)

## 도움을 주신 분

윈도우 설치와 동작을 직접 테스트해 주시고, Inno Setup 설치 스크립트까지 만들어
보내주신 **타이닛**님께 진심으로 감사드립니다.

맥만 쓰는 환경에서는 확인할 수 없었던 윈도우 쪽 문제를 짚어주신 덕분에
설치 파일이 제대로 자리를 잡았습니다.

## 1. 이 플러그인이 해결하는 문제

### 스톡 영상 하나를 타임라인에 넣기

| | 플러그인 없이 | Eddie Drop |
|---|---|---|
| **조작 횟수** | **7번** | **3번** (끌어놓기는 **2번**) |
| 1 | 브라우저를 켠다 | 패널에서 검색어를 친다 |
| 2 | Pexels 사이트에서 검색한다 | 원하는 카드를 클릭한다 |
| 3 | 영상을 고르고 해상도를 골라 내려받는다 | `,` 를 누른다 → 플레이헤드 위치에 들어감 |
| 4 | 다운로드 폴더에서 파일을 찾는다 | |
| 5 | 프리미어 프로젝트 패널로 끌어다 놓는다 | |
| 6 | 프로젝트 패널에서 더블클릭해 소스 모니터로 연다 | |
| 7 | 타임라인에 삽입한다 | |

**중간에 프로그램을 몇 번 오가나**
- 없이: 브라우저 ↔ 파인더 ↔ 프리미어 — **3개 프로그램**
- Eddie Drop: **프리미어 안에서만**

### 효과음 하나 넣기

| | 플러그인 없이 | Eddie Drop |
|---|---|---|
| **조작 횟수** | **8번** | **3번** |
| | 사이트 검색 → 로그인 → 내려받기 → 파일 찾기 → 가져오기 → 타임라인에 놓기 → **오디오 미터 보며 볼륨 수동 조절** → 라이선스 확인 | 검색 → 클릭(바로 들림) → `,` |
| 볼륨 | 귀와 미터로 직접 맞춤 | **자동으로 목표 레벨에 맞춰서 들어감** |
| 라이선스 | 소리마다 직접 확인 | **CC0만 검색되게 고정** (끌 수 없음) |

> 볼륨 자동 맞추기는 Eddie Drop만의 기능입니다. 대본에서 강조할 지점입니다.

## 2. 기능별 정리 (탭 순서대로)

패널에는 탭이 **7개** 있습니다 — 영상 · 이미지 · GIF · 스티커 · 효과음 · 내 파일 · 설정

### 2-1. 영상 탭

**한 줄** — Pexels와 Pixabay의 무료 영상을 한 화면에서 찾아 바로 타임라인에 넣습니다.

**누르는 순서**

| 순서 | 하는 일 | 결과 |
|---|---|---|
| 1 | 검색창에 단어 입력 → Enter | 결과가 소스별로 나뉘어 나옴 |
| 2 | 카드 클릭 | 파란 테두리로 선택됨 + 파일을 미리 받기 시작 |
| 3 | `,` 또는 카드의 **[삽입]** 버튼 | 플레이헤드 위치에 삽입 |
| 3' | `.` 또는 **[덮어쓰기]** | 플레이헤드 위치에 덮어쓰기 |
| 3'' | 카드를 타임라인으로 끌어놓기 | 놓은 자리에 들어감 (잠시 뒤 빈으로 정리됨) |
| — | 더블클릭 | 소스 모니터에 열림 |

**화면에 보이는 것**
- 소스 선택: **Pexels · Pixabay · 둘 다**
- 필터: `방향 전체 / 가로 / 세로 / 정사각`, `크기 전체 / 4K 이상 / FHD 이상 / HD 이상`, `색상 전체` 외 12색
- **fps 필터**: `fps 전체 / 24fps (영화) / 25fps (PAL) / 30fps / 50fps / 60fps / 50fps 이상 (슬로우모션)`
- 카드 위: 해상도 · 길이 · fps · 제작자 이름
- 카드에 마우스를 올리면 **[삽입] [덮어쓰기]** 버튼
- 맨 아래 **[더 보기]** 버튼
- 최근 검색어 칩

**속에서 일어나는 일**
1. 두 사이트에 동시에 검색 요청
2. 고른 카드의 파일을 `~/Documents/Eddie Drop/Pexels/` (또는 `Pixabay/`) 에 내려받음
3. 프로젝트의 **`Eddie Drop / Pexels`** 빈으로 불러옴 (빈 이름은 설정에서 변경 가능)
4. 타겟이 켜진 트랙에 넣음. 타겟이 없으면 **비어 있는 트랙**을 찾아서 넣음

**제약 · 주의**

| 내용 | 근거 |
|---|---|
| **fps 필터는 Pexels 결과에만** 적용됨. Pixabay는 fps 정보를 아예 주지 않음 | Pixabay API 응답에 fps 필드 없음 |
| **방향 필터는 Pexels 영상에만** 적용됨. Pixabay 영상에는 방향 옵션이 없음 | Pixabay API 문서 |
| 화질은 설정의 `영상 기본 화질`(4K / FHD / HD)을 따라 **그 이하 중 가장 큰 파일**을 받음 | |
| 파일 크기 편차가 큼 — 실측 **7 MB ~ 127 MB** (같은 검색어라도) | 실측 |
| Pexels 한도: **시간당 200회 / 월 20,000회** | [Pexels 공식 문서](https://www.pexels.com/api/documentation/) |
| Pixabay 한도: **60초당 100회** | [Pixabay 공식 문서](https://pixabay.com/api/docs/) |
| Pixabay 규정상 검색 결과를 **24시간 캐시**함 (같은 검색어를 다시 치면 즉시 나옴) | Pixabay 문서 요구사항 |

### 2-2. 이미지 탭

**한 줄** — 구조는 영상 탭과 같고, 사진을 찾습니다.

**영상 탭과 다른 점**
- 크기 필터가 `큰 사진 / 보통 / 작은 사진`
- Pixabay 전용 필터가 더 있음: **사진/그림 전체 · 실사 · 벡터**, 카테고리(배경·동물·건물·음식 등), **투명 (Pixabay만)**, **흑백 (Pixabay만)**
- fps 필터 없음
- 항상 **원본 크기**로 받음 (화질 설정은 영상에만 적용)

**주의**
- Pixabay는 **이미지 핫링크 금지** 규정이 있어서, 썸네일도 먼저 내 컴퓨터에 받아서 보여줍니다. 그래서 Pixabay 결과는 썸네일이 조금 늦게 뜹니다. ([Pixabay 문서](https://pixabay.com/api/docs/))
- **JPG 뿐 아니라 PNG 도 받습니다.** Pixabay 의 "투명" 필터로 찾은 배경 없는 이미지가 여기 해당합니다. 파일 종류는 실제 내용을 보고 정하므로 확장자가 틀리는 일이 없습니다.

### 2-3. GIF 탭

**한 줄** — GIPHY에서 짤을 찾아 **MP4로** 받아 넣습니다.

**화면에 보이는 것**
- 검색창 안내문: `GIF 검색 (예: 웃음, applause)`
- 태그 칩: 웃음 · 박수 · 축하 · 화남 · 슬픔 · 놀람 · 당황 · 좋아요 · 폭죽 · 불 · 반짝 · 생각 등
- 수위 선택: `전체 이용가 (G) / 가벼운 수위 (PG) / 중간 수위 (PG-13) / 높은 수위 (R)` — 기본은 **G**
- 카드에 **MP4** 배지

**속에서 일어나는 일**
- GIF 원본이 아니라 **MP4 파일**을 받습니다. 프리미어에서 GIF보다 훨씬 가볍기 때문입니다.
- `~/Documents/Eddie Drop/GIPHY/` 에 저장 → `Eddie Drop / GIPHY` 빈으로 불러옴

**제약 · 주의**

| 내용 | 근거 |
|---|---|
| 패널에 **"Powered by GIPHY"** 표기가 들어가 있음 (GIPHY 약관 요구) | GIPHY 약관 |
| GIPHY 결과는 다른 사이트 결과와 **같은 그리드에 섞지 않음** (탭을 따로 둔 이유) | GIPHY 약관 |
| 패널이 직접 띄우는 경고: **"방송·영화 장면 짤은 저작권이 있을 수 있어요. 수익화 영상에서는 주의하세요."** | 코드에 있는 실제 문구 |
| 한글보다 **영어 검색어가 결과가 훨씬 많음** (패널도 그렇게 안내함) | |
| 무료(베타) 키 한도: **시간당 100회** — ※GIPHY 고객센터 페이지가 직접 열리지 않아(HTTP 403) 검색 결과로만 확인했습니다. **확인 필요** | |

### 2-4. 스티커 탭

**한 줄** — GIPHY 스티커를 **투명 배경 그대로** 받아 넣습니다.

**GIF 탭과 다른 점**
- 받는 파일이 **MP4가 아니라 GIF 원본** — 투명 배경을 살려야 하기 때문
- 카드 배경이 **체크무늬**로 보임 (투명하다는 표시)
- 태그 칩이 다름: 하트 · 별 · 화살표 · 체크 · 느낌표 · 말풍선 · 이모지 등
- 안내 문구: `스티커는 투명 배경 GIF로 받습니다.`

**투명 배경 — 실제로 확인함**
받아둔 스티커 GIF **16개 전부** 파일 안에 투명 정보가 들어 있는 것을 직접 확인했습니다.
→ 프리미어에 넣으면 배경 없이 올라갑니다. **영상에서 보여주기 좋은 장면입니다.**

### 2-5. 효과음 탭

**한 줄** — Freesound에서 **출처 표기가 필요 없는 소리(CC0)만** 찾아, **볼륨까지 맞춰서** 넣습니다.

**누르는 순서**

| 순서 | 하는 일 | 결과 |
|---|---|---|
| 1 | 검색어 입력 또는 태그 칩 클릭 | 목록이 나옴 |
| 2 | **줄을 클릭하면 바로 소리가 남** | 파형과 함께 재생 |
| 3 | `Tab` / `Shift+Tab` | 다음 / 이전 소리로 넘어가며 자동 재생 |
| 4 | `,` 또는 **[삽입]** | 오디오 트랙에 볼륨이 맞춰져 들어감 |

**화면에 보이는 것**
- 검색창 안내문: `효과음 검색 (예: 휘릭, whoosh)`
- 태그 칩 20개: 뿅 · 띠링 · 알림 · 클릭 · 타자 · 카메라 셔터 · 박수 · 웃음 · 성공 · 실패 · 에러 · 발소리 · 문 · 비 · 바람 · 폭발 · 글리치 · 전환 · 레트로 게임 · 휘릭 (설정에서 추가·삭제 가능)
- 길이 필터: `길이 전체 / 짧게 (0~3초) / 보통 (3~15초) / 길게 (15초~)`
- 정렬: `관련도순 / 많이 받은 순 / 별점 높은 순 / 짧은 순`
- 각 줄: 파형 그림 · 제목 · **CC0 배지** · 길이 · 태그
- **미리듣기 볼륨** 슬라이더
- 맨 아래 고정 문구: **`🔓 CC0 라이선스만 검색됩니다 (출처 표기 없이 사용 가능)`**
- 넣고 나면 상태바에 예: `삽입 완료 · A1 트랙 · 레벨 -8.2dB (피크 -0.3→-8.5dB)`

**볼륨 자동 맞추기 — 어떻게 도는가**
1. 받은 파일을 열어 **가장 큰 소리(피크)가 몇 dB인지** 잽니다 (앞 120초까지만 봄)
2. 목표치(기본 **-15 dB**, 설정에서 -30 ~ 0 사이로 조절)에 맞추려면 볼륨을 얼마나 올리고 내려야 하는지 계산
3. 그 값을 **클립 볼륨에 직접 넣어서** 타임라인에 배치
→ 효과음마다 볼륨이 들쭉날쭉하지 않습니다.

**제약 · 주의 — 대본에서 중요**

| 내용 | 근거 |
|---|---|
| **원본 파일이 아니라 미리듣기용 MP3를 받습니다.** Freesound는 원본 다운로드에 OAuth2 로그인을 요구하는데, 지금은 API 키 방식만 씁니다 | [Freesound 공식 문서](https://freesound.org/docs/api/overview.html) |
| 그 MP3 실측 음질: **44.1 kHz 스테레오, 약 100~235 kbps** (파일당 평균 171 KB) | 받아둔 68개 실측 |
| → **효과음(휘릭·뿅·클릭)에는 충분하지만, 음악이나 긴 앰비언스를 이 음질로 쓰는 건 권하지 않습니다** | |
| **CC0만 검색되고 사용자가 끌 수 없습니다.** 서버 필터에 더해 패널이 받은 결과를 한 번 더 걸러냅니다 | 코드 |
| Freesound 한도: **분당 60회 / 하루 2,000회** | Freesound 공식 문서 |
| 한글로 쳐도 아는 단어는 영어로 바꿔 찾습니다 (사전 내장) | |

### 2-6. 내 파일 탭

**한 줄** — 내 컴퓨터에 있는 소스를 프로젝트 패널처럼 훑어보고 바로 넣습니다.

**누르는 순서**
1. **[폴더 선택]** → 폴더 고르기
2. 파일 클릭 (소리 파일은 바로 들림) → `,` 삽입 / `.` 덮어쓰기 / 더블클릭 소스 모니터
3. 또는 **[이 폴더 전체를 프로젝트로 불러오기]** — 보이는 파일을 폴더 이름의 빈으로 한 번에 넣음

**화면에 보이는 것**
- **[폴더 선택] [↑ 상위] [새로고침]**
- 자주 쓰는 폴더 칩 (**최대 6개**, 자동 기억)
- **[썸네일 보기] / [목록 보기]** 전환 — 목록 보기는 프로젝트 패널처럼 작은 유형 아이콘만
- 종류 필터: `전체 / 영상 / 이미지 / 효과음 · 음악`
- 정렬 **7가지**: 이름순 (가나다) / 이름 거꾸로 / 종류순 / 크기순 (큰 것부터) / 크기순 (작은 것부터) / 최근 추가순 / 오래된 순
- `하위 폴더까지` 체크박스
- 파일 이름 검색창

**읽는 파일 종류**

| 종류 | 확장자 |
|---|---|
| 영상 | mp4 · mov · m4v · avi · mkv · webm · mxf · mpg · mpeg · wmv |
| 이미지 | jpg · jpeg · png · gif · tif · tiff · webp · bmp · heic |
| 소리 | mp3 · wav · aif · aiff · m4a · flac · ogg · aac |

**제약 · 주의**

| 내용 |
|---|
| 한 폴더에 **400개까지만** 보여줍니다. 넘으면 `(400개까지만)` 이라고 표시됩니다 |
| `하위 폴더까지` 를 켜도 **3단계 아래까지만** 훑습니다 |
| **MOV / ProRes 파일은 썸네일과 미리보기가 안 나옵니다.** 브라우저 엔진이 그 코덱을 못 읽기 때문입니다. `🎬` 아이콘과 확장자만 보입니다 → **이런 파일이 많은 폴더는 [목록 보기]를 쓰세요** |
| 이 탭에는 최근 검색어 기능이 없습니다 (다른 탭에는 있음) |

### 2-7. 설정 탭

### 돌아가는 환경

| | |
|---|---|

| 맥 | macOS (인텔·애플 실리콘 모두) |
| 윈도우 | Windows 10 이상 |

### 설치 순서

설치 파일이 준비돼 있습니다. 릴리스에서 받아 실행하면 됩니다.
https://github.com/jazzman0708-jpg/eddie-drop/releases/latest

| 내 컴퓨터 | 받을 파일 | 관리자 암호 |
|---|---|---|
| 맥 | `EddieDrop-1.0.7-mac.pkg` | 필요 없음 |

1. **프리미어를 완전히 종료한다** (켜둔 채로 깔면 패널이 안 뜹니다)
2. 설치 파일을 실행한다
   - 맥: **오른쪽 클릭 → 열기** (그냥 두 번 클릭하면 "확인되지 않은 개발자" 경고에 막힘)
   - 윈도우: 파란 경고창에서 **추가 정보 → 실행**
3. 프리미어를 켜고 **창 → 확장명 → Eddie Drop**

> 두 경고 모두 **코드 서명 인증서를 안 샀기 때문**입니다 (맥 연 129달러, 윈도우 연 수십만 원).

**업데이트는 설치 파일을 다시 받을 필요가 없습니다.**
설정 → 업데이트 → [업데이트 확인] 을 누르면 패널이 알아서 받습니다.

### API 키 4개 — 발급받는 곳과 무료 한도

| 사이트 | 발급 주소 | 무료 한도 (공식 문서) | 비용 |
|---|---|---|---|
| **Pexels** | pexels.com/api/ | 시간당 200회 · 월 20,000회 | 무료 |
| **Pixabay** | pixabay.com/api/docs/ | 60초당 100회 | 무료 |
| **GIPHY** | developers.giphy.com/dashboard/ | 베타 키 시간당 100회 「확인 필요」 | 무료 (상용 확장은 유료) |

**키를 넣는 법**
설정 탭 → 해당 칸에 붙여넣기 → **바로 저장됨** → **[연결 테스트]** 를 눌러 `연결 성공` 확인

**키가 저장되는 곳** (코드에는 절대 안 들어감)
```
맥   ~/Library/Application Support/Eddie/shared-settings.json
윈도 %APPDATA%\Eddie\shared-settings.json
```
→ 다른 에디 플러그인과 **함께 씁니다. 한 번만 넣으면 됩니다.**

## 4. 단축키 · 조작

### 지금 실제로 동작하는 것

| 키 | 하는 일 | 언제 되나 |
|---|---|---|
| **클릭** | 고르기 (효과음·소리 파일은 바로 재생) | 항상 |
| **더블클릭** | 소스 모니터에 열기 | 항상 |
| **Tab** | 다음 결과 | 패널에 포커스가 있을 때 |
| **Shift+Tab** | 이전 결과 | 패널에 포커스가 있을 때 |
| **Space** | 미리보기 / 미리듣기 | 패널에 포커스가 있을 때 |
| **`,`** | 플레이헤드 위치에 **삽입** | 패널에 포커스가 있을 때 |
| **`.`** | 플레이헤드 위치에 **덮어쓰기** | 패널에 포커스가 있을 때 |
| **[삽입] [덮어쓰기] 버튼** | 위와 같음 | 항상 — **가장 확실한 방법** |
| **끌어놓기** | 타임라인이나 프로젝트 패널에 놓기 | 항상 |

### `,` `.` 에 대한 솔직한 설명 — **대본에서 반드시 짚어야 할 부분**

패널에서 `,` 를 누르면 **프리미어도 같이 반응합니다.**

- 원인: CEP(어도비 확장 규격)에서 키를 가로채는 기능이 실제로는 동작하지 않습니다. 어도비 쪽 알려진 문제입니다.
- 증상: 소스 모니터에 다른 클립이 열려 있으면 **그 클립도 같이 삽입**됩니다.
- 그래서: 깔끔하게 넣으려면 **카드의 [삽입] 버튼**이나 **끌어놓기**를 쓰세요.
- 설정 탭에도 이 경고가 그대로 적혀 있습니다.

### 안 되는 키

| 키 | 왜 안 되나 |
|---|---|
| **방향키 (↑ ↓ ← →)** | 프리미어가 놓아주지 않아 타임라인이 움직입니다. 그래서 **Tab / Shift+Tab 으로 대체**했습니다 |
| **Enter** | 프리미어의 인/아웃 렌더가 같이 돌아버려서 **일부러 뺐습니다**. 더블클릭으로 대신하세요 |

## 5. 시연 시나리오 3개

> **측정 조건** — Premiere Pro 26.3.0 / macOS / 검색 캐시를 비우고 처음 검색하는 상태로 실측.
> 인터넷 속도와 파일 크기에 따라 달라집니다. **아래는 "이 정도로 빠르다"는 참고값이지, 보장값이 아닙니다.**

### 시나리오 ① 브이로그 B롤 채우기

- **검색어: `autumn forest`** (영상 탭)
- 흐름: 검색 → 카드 클릭 → `,`
- **실측: 검색 1.1초 + 넣기 0.6초 = 약 1.7초** (7.4 MB 파일)
- 단, 큰 파일은 더 걸립니다 — `sunset beach` 로 127 MB 짜리를 받았을 때는 **넣기까지 8.7초**
- 보여줄 포인트: **fps 필터** — `24fps (영화)` 를 골라서 내 시퀀스 프레임레이트에 맞는 것만 고르는 장면

### 시나리오 ② 정보전달 영상에 짤 넣기

- **검색어: `facepalm`** (GIF 탭) / 스티커는 **`arrow`** 또는 **`하트`**
- 흐름: 검색 → 카드 클릭 → `,`
- **실측: 검색 1.0초 + 넣기 0.6초 = 약 1.6초**
- 보여줄 포인트:
  - GIF는 **MP4로 받아서** 프리미어가 가볍게 돌아간다는 점
  - **스티커 탭에서 투명 배경**이 그대로 살아나는 장면 (확인 완료 — 잘 나옵니다)

### 시나리오 ③ 효과음 붙이기

- **검색어: `magic sparkle`** 또는 태그 칩 **`휘릭`**
- 흐름: 태그 클릭 → 줄 클릭(바로 들림) → `Tab` 으로 몇 개 넘겨 듣기 → `,`
- **실측: 검색 2.1초 + 넣기 2.0초 = 약 4.1초** (볼륨 재는 시간 포함)
- 결과 표시: `삽입 완료 · A1 트랙 · 레벨 -8.2dB (피크 -0.3→-8.5dB)`
- 보여줄 포인트 — **이 시나리오가 제일 강합니다**
  1. `Tab` 만 눌러서 소리를 착착 넘겨 듣는 장면
  2. 넣자마자 **오디오 미터**가 목표 레벨에 딱 맞는 장면
  3. 맨 아래 **CC0 배지**를 보여주며 "출처 안 적어도 된다" 설명

## 7. 촬영 전 확인 목록

### 프리미어 쪽

- [ ] **시퀀스를 미리 만들어 둘 것** — 없으면 `시퀀스를 먼저 열어주세요.` 만 뜹니다
- [ ] 트랙을 **V1~V3, A1~A4 정도** 만들어 둘 것 (빈 트랙이 없으면 "맨 위 트랙에 넣었어요" 경고가 뜹니다)
- [ ] **소스 모니터를 비워 둘 것** — 뭔가 열려 있으면 `,` 를 눌렀을 때 그것도 같이 들어가서 화면이 지저분해집니다
- [ ] 시퀀스 프레임레이트를 정해 둘 것 (fps 필터 시연을 하려면)
- [ ] **오디오 미터를 화면에 띄워 둘 것** — 볼륨 자동 맞추기가 시각적으로 보여야 설득력이 생깁니다

### Eddie Drop 쪽

- [ ] API 키 4개 모두 `연결 테스트` **연결 성공** 확인
- [ ] 설정 → **효과음 목표 레벨**을 **-15dB** 로 되돌릴 것 ⚠️ **지금 -8.5dB 로 되어 있습니다**
- [ ] 설정 → **검색 결과 캐시 비우기** — 캐시가 있으면 검색이 너무 빨리 끝나서 "실제로 찾고 있다"는 느낌이 안 납니다. 반대로 빠른 걸 보여주려면 캐시를 남겨두세요
- [ ] 다운로드 폴더를 한번 비우거나, 파인더로 열어서 파일이 쌓이는 걸 보여줄 준비
- [ ] 내 파일 탭 시연용 **폴더 하나 준비** (영상·이미지·소리가 섞인 폴더가 좋습니다)

### 화면 배치

- [ ] Eddie Drop 패널을 **세로로 길게** 두는 게 좋습니다 (카드가 2~3열로 보임)
- [ ] 패널 · 타임라인 · 오디오 미터가 **한 화면에 같이** 보이게
- [ ] 화면 녹화 해상도에서 패널 글자가 읽히는지 미리 확인

### 미리 찍어둘 장면

- [ ] 스티커 투명 배경 (확실히 잘 나옵니다)
- [ ] 효과음 `Tab` 연타로 넘겨 듣기
- [ ] 효과음 넣은 직후 오디오 미터
- [ ] 끌어놓기로 타임라인에 바로 놓기
